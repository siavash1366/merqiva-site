# پایلوت تک‌شرکتی مرکویوا

این گردش‌کار پیش‌نویس است؛ اجرای واقعی AvalAI هنوز انجام نشده است.

- فقط Astro Offshore؛ یک درخواست و حداکثر دو فراخوانی ابزار جست‌وجو و ۴۰۰۰ توکن خروجی؛ تکرار خودکار خاموش.
- انتخاب مدل gpt-5.6-luna براساس نمونه رسمی AvalAI؛ دسترسی حساب و قیمت قطعی هنوز تأیید نشده است.
- runApproved پیش‌فرض false است و قبل از تماس بیرونی اجرا را متوقف می‌کند.
- اتصال AvalAI و جدول باید در محیط n8n انتخاب شوند؛ هیچ کلید یا شناسه اتصال خصوصی در فایل نیست.
- جدول Merqiva_Pilot_Review باید سه ستون متنی jobId، status و payload داشته باشد. ذخیره از طریق نگاشت خودکار نام ستون‌ها است.
- اعتبارسنج قبلاً در n8n با داده مصنوعی آزموده شده؛ گردش‌کار جدید و نوشتن جدول هنوز اجرا نشده‌اند.
- اطلاعات استفاده و مراجع نگهداری می‌شوند؛ هزینه واقعی فقط با صورتحساب سرویس مشخص می‌شود. این محدودیت‌ها سقف قطعی دلاری نیستند.
- قبل از فعال‌کردن runApproved، کلید اتصال و قیمت روز و بودجه حساب بررسی شوند. فقط یک بار دستی اجرا شود. پس از تایم‌اوت، بدون بررسی صورتحساب درخواست تکرار نشود.
- این آزمایش فاقد وب‌هوک، زمان‌بندی و ارسال نتیجه به وب‌سایت اصلی است. آزمون callback و Cloudflare KV با آن پوشش داده نمی‌شود.
